## Why

Onix's reusable Tenstorrent package, RWKV/ttWKV7 harness, and retained evidence code currently lives inside `onix-core` while the repository also consumes an external `tenstorrent.nix` input. This splits package ownership, makes the reusable work difficult to consume independently, and couples accelerator development to workstation and fleet configuration.

## What Changes

- Establish `github:OnixResearch/tenstorrent.nix` on `main`, preserving the upstream `RossComputerGuy/tenstorrent.nix` lineage at the exact revision already pinned by `onix-core`.
- Port the current reusable Tenstorrent package snapshot, device-free validation checks, bounded device wrappers, benchmark core, simulator, and immutable evidence fixtures into that dedicated flake.
- Keep host inventory, service ownership, secrets, deployment configuration, and unrelated Cairn changes in `onix-core`.
- Repoint `onix-core` to the OnixResearch input and consume migrated outputs instead of maintaining duplicate package sources.

## Impact

- **Files**: the sibling `tenstorrent.nix` checkout; `onix-core` flake input/output wiring, Tenstorrent package directories, host package references, README references, lockfile generated by Nix, and this Cairn change package
- **Testing**: pre/post device-free RWKV checks, dedicated flake evaluation and focused checks, negative output-boundary assertions, `onix-core` evaluation, formatting, and Cairn validation
