## Why

The sole authorized executable-runbook attempt reached the composed ttWKV7 probe wrapper but returned status 127 before device initialization. The wrapper retained a runtime `$out` expression, inherited the checkout's `out` value, and dispatched to a nonexistent path even though package validation passed. The fourteen exact constant masks therefore remain unmeasured.

## What Changes

- Embed the composed package's immutable probe-runtime wrapper path during the Nix build instead of resolving `$out` at runtime.
- Exercise the actual production wrapper with `out` absent and hostile, and reject unexpanded output-variable targets or fake-only dispatch coverage.
- Rebuild the package, dual-architecture check, and complete host closure without touching hardware.
- Prepare a fresh executable one-shot with independent rollback, exact immutable inputs, a unique evidence root and Inspector port, and zero invocation state.
- Consume at most one newly authorized device-1 probe process with no fallback, alternate command, or retry, then restore and classify honestly.

## Impact

- **Files**: `pkgs/ttwkv7/probe-wrapper.sh`, `pkgs/ttwkv7/runtime.nix`, and this Cairn change; a committed one-shot runbook is added only after the repaired package store path is known.
- **Testing**: baseline package behavior, positive and negative production-wrapper checks, exact package build, Blackhole/Wormhole architecture compilation, complete host closure, Bash syntax, ShellCheck, Cairn validation and gates, strict owner/root/timer/runtime preflights, exactly one bounded physical process, and retained service/endpoint/board restoration evidence.
- **Claims**: Passing all fourteen masks would establish only exact constant-tile generation for the reviewed package and selected Blackhole P150. It does not establish full-WKV, decode, performance, or broad P150 compatibility.
