## Context

The requested dataset is a one-off snapshot containing 3,148,796 metadata records, 2,856,227 assembled paper texts and 16.08 TB across all configurations. Paper licenses vary; source text is unversioned LaTeX, not guaranteed clean prose. Laya's root checkpoint is an English 421M-parameter typed decision model, not a chat or embedding model.

## Decisions

### Decision: Aspen2, CPU-only and private

Aspen2 (100.82.25.30) had approximately 53 GiB available RAM and 1.6 TiB free disk during placement inspection. The desktop had only 2.3 GiB available RAM and full swap. Run the corpus API on port 7998 and Laya on 7999, bound only to Aspen2's Tailscale address. Dedicated DynamicUser units get persistent state, memory/CPU limits and no GPU devices. Scope activation to the research services, the two Mesh sidecars, and the research-only ingress; do not activate unrelated host changes.

### Decision: Full metadata, selective text

Pin `secemp9/arxiv-complete` at `cee894837962fede5612cccf2a4c7cacf49b4c3a`. Import every metadata shard into an atomic SQLite FTS5 index. Build paper-text range lookup from Parquet footers, then fetch only a matching row group. Verify the returned text digest and paginate by Unicode characters. Preserve metadata, citations and licenses. Never mirror the 16 TB repository or silently substitute the 991-paper sample. Missing text and upstream failures are distinct results.

### Decision: Native Laya SDK without remote code

Pin SDK 0.3.4 and checkpoint `1c5edc17a7acd8701df6fc341c0d179f1c62c982`. Load only root weights, tokenizer and encoder configuration on CPU. The SDK receives local assets with Hub/Transformers offline mode after preparation; downloaded Python is never imported. Its tokenizer normalization operates on a private config copy, not the immutable cached blob. Serve choice, score and noul requests serially with bounded bodies and batches.

### Decision: Native discoverable OMP tools

The managed extension registers read-only `arxiv_corpus` search/read and `laya_decide` tools against the desktop's research-only Mesh ingress at `http://100.110.43.11:7997`. The native plugin and OMP share `pkgs/mesh-research/operations.json`; there is no direct-backend fallback. Calls carry cancellation and a 90-second deadline, return structured provenance, and bound response size. Existing model discovery and default-model settings remain unchanged. Install the same generated extension on the desktop and current workstation; existing sessions require a restart or extension reload.

## Risks / Trade-offs

- Search is lexical over metadata, not semantic or full-paper search; text retrieval still depends on Hugging Face availability.
- The snapshot is not live arXiv. Each response identifies its immutable revision and each paper retains its own license.
- Laya's 512-token context includes its question/options; long inputs can truncate. Root-model predictions are English-only and not domain-calibrated or authorization decisions.
- Tailscale authentication/network policy protects the endpoints; no public listener or public firewall opening is introduced.
